Continuum Platform has been deployed.

Components:
  - Cluster Manager (workbench lifecycle)
  - API Server
  - Orchestration Service
  - Message Bridge
  - Credentials Server

To verify the deployment:

  kubectl get pods -n {{ .Release.Namespace }} -l app.kubernetes.io/instance={{ .Release.Name }}

Access the platform. There is no single entry point in this chart: each service has its own ClusterIP Service, so
port-forward the one you need, or put your own ingress / reverse proxy in front of them.

  # Cluster Manager (workbench lifecycle API and UI)
  kubectl port-forward svc/{{ include "continuum-platform.cluster-manager.fullname" . }} 8082:8080 -n {{ .Release.Namespace }}
  # Open the UI: http://localhost:8082/ui/

  # API Server (workflow API, node registry)
  kubectl port-forward svc/{{ include "continuum-platform.api-server.fullname" . }} 8080:8080 -n {{ .Release.Namespace }}

  # Credentials Server (credential API and UI)
  kubectl port-forward svc/{{ include "continuum-platform.credentials-server.fullname" . }} 8083:8080 -n {{ .Release.Namespace }}
  # Open the UI: http://localhost:8083/ui/
